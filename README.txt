Brandland — ملفات واجهات متجر عربي تجريبي
=========================================
الصفحات:
- index.html          الصفحة الرئيسية
- categories.html     الأقسام
- products.html       جميع المنتجات والفلاتر والترتيب
- product.html        تفاصيل المنتج
- cart.html           سلة المشتريات (إضافة/حذف/تعديل الكمية)
- checkout.html       إتمام الطلب والدفع عند الاستلام
- order-success.html  تأكيد الطلب
- order-track.html    تتبع الطلب التجريبي
- account.html        صفحة حسابي
- menu.html           القائمة والأسئلة الشائعة والتواصل
- admin.html          لوحة تحكم شكلية
- style.css           الهوية والتنسيقات المتجاوبة
- app.js              وظائف الواجهة والتفاعل
- assets/             مجلد الصور والأصول

طريقة التشغيل:
1. فك ضغط ملف Brandland_Store.zip.
2. افتح index.html في متصفح حديث (Chrome مثلاً).
3. انتقل بين الصفحات من الروابط والقوائم.
4. جرّب إضافة منتج للسلة، تعديل الكمية، ثم إتمام الطلب.
   الدفع مضبوط على "عند الاستلام" في الواجهة.

ملاحظات مهمة:
- هذا قالب Front-end تجريبي يعمل محلياً ويخزن السلة والطلبات في localStorage في المتصفح.
- لا توجد قاعدة بيانات أو لوحة إدارة فعلية أو إرسال طلبات إلى صاحب المتجر.
- لا توجد بوابة دفع أو خدمة توصيل مرتبطة؛ الدفع عند الاستلام معروض في الواجهة فقط.
- أسماء المنتجات والأسعار والمواصفات أمثلة تصميمية ويجب استبدالها بالمعلومات الحقيقية.
- قبل نشر المتجر للزبائن، يلزم ربطه بخلفية آمنة، وإدارة مخزون وطلبات، ووسيلة تواصل حقيقية، ومراجعة المتطلبات القانونية وسياسات المنتجات والشحن في بلد التشغيل.
